## What we build

ExpinSoft is a software agency. The public repositories below are real,
working examples (not case-study writeups) of the kinds of problems we
solve for clients:

| Problem domain | Example repo | Stack |
|---|---|---|
| API integrations for e-commerce (catalog sync, caching) | [pencarrie-api-integration](https://github.com/expinsoft-solutions/pencarrie-api-integration) | Next.js, TypeScript |
| Booking / marketplace web platforms | [doorstep](https://github.com/expinsoft-solutions/doorstep) | Next.js, TypeScript, Tailwind |
| Marketplace data automation & feed transformation | [pg-utility-tools](https://github.com/expinsoft-solutions/pg-utility-tools) | Next.js, TypeScript, ExcelJS |
| Assessment platforms with admin portals & scoring engines | [talentrank-quiz-site](https://github.com/expinsoft-solutions/talentrank-quiz-site) | Next.js, Supabase |
| Corporate/marketing websites with automated deploys | [expisoft-website](https://github.com/expinsoft-solutions/expisoft-website) | Next.js, GitHub Actions |
| Media processing & multi-channel upload automation | [sgs-got-samples](https://github.com/expinsoft-solutions/sgs-got-samples) | Next.js, Node.js/Prisma, Python/FastAPI |

Each linked repo has its own README with setup instructions, and an
MIT LICENSE.

## How we work

- **Security**: org-wide vulnerability reporting policy in
  [`.github`](https://github.com/expinsoft-solutions/.github/blob/main/.github/SECURITY.md)
- **Accessibility**: frontend projects are built with WCAG 2.1 AA as a
  target, not an afterthought
- **CI/CD**: projects with automated deploy pipelines document them in
  their own README (see `expisoft-website`)
